# История версий

## v1.3.0 — 2026-10-25

Прошивка **1.1.10**, панель Smart Life **1.0.23**.

- Справочник растений `/plants.ini` на SD: «Имя=порог влажности, %», при первом запуске создаётся таблица из 25 дачных культур. Файл можно править вручную.
- DP 180 `plants` (страница справочника) и DP 181 `plant_cmd` (`list:N`, `add:Имя=60`, `del:Имя`, `reset`).
- 1.1.10 / 1.0.21: +5 культур (патиссоны, кукуруза, базилик, шпинат, сельдерей) — старый plants.ini дополняется сам; имя грядки — комбобокс с поиском по справочнику, список по алфавиту; надёжная догрузка всех страниц.
- Панель: в диалоге имени грядки — список растений; выбор ставит имя и порог влажности грядки. Своё растение можно сохранить в справочник или убрать из него.

## v1.2.0 — 2026-10-24

Прошивка **1.1.8**, панель Smart Life **1.0.19**, навыки Алисы.

### Прошивка
- 1.1.8: служебная информация (время контроллера, импульсы расходомера) уходит в облако раз в минуту, а не раз в 10 минут.
- 1.1.7: пуш «Нет потока воды» (клапан открыт 2 мин без импульсов, не чаще раза в 6 ч); команда `flow` в COM-порт; расходомер проверен на плате.
- 1.1.5: переключатели «Работать ночью» и «Работать в дождь» применяются сразу.
- 1.1.6: имена грядок хранятся на контроллере (DP 171–178 `name_N`), по умолчанию «Растение N».
- Пуш «Грядка <имя> пересохла: N %» (DP 179 `alert`); по выключенным грядкам пушей нет, первые 5 минут после включения — тоже.

### Панель
- 1.0.19: переименование грядки уходит на контроллер (имя видно в пушах и у Алисы).

### Алиса (папка `alice/`, одна функция Яндекс Облака)
- Навык «Умный дом» «Капельный полив»: дом «Дача», комната «Улица».
  Грядки «Растение N» (вкл = всегда включено, выкл = выключено, влажность),
  выключатели «Растение N автополив» и «Растение N в парнике», общие «Полив», «Автополив»,
  «Полив в парнике», «Дренаж», датчик «Контроллер полива».
- Разговорный навык «Дачный полив»: «Алиса, спроси у дачного полива, какая влажность сейчас /
  какая влажность кабачков / что растёт на грядке 5».
- Своя привязка аккаунта (OAuth), имена устройств не длиннее 25 символов.
- Полный список фраз — `alice/commands.html`.

### Файлы релиза
- `drip_1.1.8.bin` — прошивка (OTA Tuya или адрес `0x10000`).
- `drip-alice.zip` — код облачной функции для Яндекс Облака.

## v1.1.4 — 2026-10-23

Прошивка **1.1.4**, панель **1.0.18**. Наладка на плате-носителе: все узлы проверены.

### Прошивка
- Исправлено: «Режим для всех грядок» не применялся (команда `mode_all` отвергалась).
- Исправлено: дренаж, залив бака и пусковое окно насоса выключались сразу после команды из приложения.
- Режим и порог грядки применяются сразу, а не в начале следующей минуты.
- Новая настройка `pump_start_sec` (DP 127): сколько секунд держать насос после открытия клапана, 0…600 с, 0 — не включать.
- Реле переназначены под проводку: насос и дренаж — клеммник J5, залив бака — J7.
- Границы датчиков влажности по умолчанию — замер на плате: вода 1015, сухо 3240 (разово применяются к сохранённым настройкам).
- Сервисные команды в COM-порт: `relays` — щёлкнуть всеми реле по очереди, `state` — что включено.
- Тихая сборка (`LOG_LEVEL=3`).

### Панель
- 1.0.17: кнопки режимов подсвечиваются сразу при нажатии; виден общий режим всех грядок.
- 1.0.18: настройка «Насос при открытии клапана, с».

### Файлы релиза
- `drip_1.1.4.bin` — для OTA в консоли Tuya и для прошивки по адресу `0x10000`.

## v1.1.3 — 2026-10-11

Первый публичный релиз: контроллер полностью работает через облако Tuya.
Прошивка **1.1.3**, панель Smart Life **1.0.16**.

Железо — из [DripIrrigation](https://github.com/akprof2000/DripIrrigation)
(плата-носитель, BOM, сборка), пины те же.

### Прошивка (ESP32, C++)

- Переход с MicroPython на C++ (PlatformIO): вдвое больше свободной памяти
  после подключения к облаку, место для новых функций.
- Клиент облака Tuya на протоколе TuyaOpen 2.3 (активация, MQTT, AES-GCM),
  58 data points из `spec/dp.json`.
- Логика полива перенесена из DripIrrigation: решение по клапанам, ночь и дождь,
  парник, насос давления, дренаж, заливка бака, мастера калибровки, контроль
  засора фильтра.
- Очередь отчётов на время без интернета (SD или флеш), отправка с исходным временем.
- Подтверждение команд из приложения отчётом — приложение больше не повторяет команды.
- Портал Wi-Fi: открытая точка доступа, список сетей, QR привязки к Tuya, сам
  поднимается через 3 минуты без сети и держится, пока устройство не привязано.
- Состояние периферии в `sys_info`: часы, SD, плата клапанов, датчики.
- OTA через облако Tuya во второй раздел с автоматическим откатом; публичные DNS
  после подключения (роутер не всегда резолвит CDN Tuya), запасной источник CDN.

### Панель Smart Life

- Русский, английский, китайский; выбор языка в настройках.
- Грядки, вода, события, настройки; статус периферии.
- Графики влажности: по часам за день, по дням за неделю и месяц; листание
  периодов стрелками и выбор дня в календаре.
- График клапана «Открыт / Закрыт» за день.
- Расход воды по дням за неделю и месяц.
- Все кнопки диалогов на языке панели («Да», «Отмена»).

### Облако

- Push-уведомления: засор фильтра, авария платы клапанов, контроллер не в сети
  30 минут — с русским, английским и китайским текстом.

### Файлы релиза

- `drip_1.1.3.bin` — образ приложения: для OTA в консоли Tuya и для прошивки
  по адресу `0x10000` (схема разделов `min_spiffs`).

### Известное

- Сборка с подробным логом (`LOG_LEVEL=4`); для тихой работы соберите с `LOG_LEVEL=3`.
- Tuya рекомендует не больше 40 DP; у продукта 58.
