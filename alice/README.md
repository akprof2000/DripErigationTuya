# Навык «Умный дом» для Алисы

Алиса → навык (функция в Яндекс Облаке) → облачный API Tuya → контроллер.
Раз в минуту функция отправляет состояние в Яндекс — на нём работают сценарии и уведомления.

## Устройства в «Доме с Алисой»

| Устройство | Что умеет | Пример фразы |
|---|---|---|
| Грядка 1…8 (кран, имя — как в Smart Life, по умолчанию «Растение N») | вкл = «Всегда вкл», выкл = «Выкл»; влажность | «включи кабачки», «какая влажность у кабачков» |
| «<имя> автополив», «<имя> полив в парнике» (выключатели у каждой грядки) | вкл = Авто / Парник (поливает и в дождь), выкл = Выкл | «включи автополив растения 3», «включи полив в парнике кабачков» |
| Полив | то же для всех грядок | «выключи полив», «включи полив на 10 минут» |
| Автополив, Полив в парнике | режим для всех грядок сразу | «включи автополив», «выключи полив в парнике» |
| Дренаж | разовый пролив 12 с | «включи дренаж» |
| Контроллер полива (датчик) | события: засор фильтра (`water_level: low`), авария клапанов (`water_leak: leak`), дождь (`open: opened`), минимальная влажность | для сценариев и уведомлений |

## Разговорный навык «Полив» (вопросы о грядках)

«Алиса, спроси у Полива, какая влажность сейчас» / «…какая влажность кабачков» / «…что растёт на грядке 5».
Тот же код функции, путь `/dialog`. Яндекс Диалоги → «Навык в Алисе», приватный, Webhook URL `https://<шлюз>/dialog`,
имя активации — «Полив». Можно запускать и сразу вопросом: «Алиса, попроси Полив сказать влажность грядки 2».

## Развёртывание

1. **Tuya**: platform.tuya.com → Cloud → Development → Create Cloud Project
   (Smart Home, дата-центр Central Europe). В проекте: Devices → Link App Account (QR в Smart Life),
   Service API — IoT Core, Authorization. Для продукта Drip Irrigation 8ch включить
   режим команд **DP Instruction**. Нужны Access ID и Access Secret проекта.
2. **Яндекс Облако**: функция Python 3.12, точка входа `index.handler`, код — файлы этой папки
   (без зависимостей). Переменные окружения — см. начало `index.py`.
3. **API Gateway** по `api-gateway.yaml` (подставить id функции и сервисного аккаунта с ролью
   `functions.functionInvoker`).
4. **Яндекс Диалоги** → навык «Умный дом», приватный:
   * Endpoint URL: `https://<шлюз>/` (Яндекс сам добавит `/v1.0/...`);
   * Авторизация: URL авторизации `https://<шлюз>/oauth/authorize`,
     URL токена `https://<шлюз>/oauth/token`, идентификатор и секрет — как `ALICE_CLIENT_ID/SECRET`.
5. **Таймер** раз в минуту на ту же функцию — уведомления об изменении состояния
   (нужны `YANDEX_SKILL_ID` и OAuth-токен разработчика навыка `YANDEX_OAUTH_TOKEN`).
6. В приложении «Дом с Алисой»: «Добавить устройство» → навык → вход паролем `ALICE_PASSWORD`.
